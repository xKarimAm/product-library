A dashboard that checks its own notes

Product Library

Every project I've started with Claude Code, as a SimCity-style city. Local and read-only. It shows which notes about my work are still true.

Why I built it

I don't trust notes. Mine or Claude's.

Every project ends with a note: "next: add tests", "tests pass, commit 4f9e2a1". Weeks later I come back and ask: where did I leave off, and is that note still true?

git log tells me what happened. It doesn't tell me the note is out of date, or that the commit it cites was never made.

The core idea

Three ways a note lies, three cheap checks

It's out of date

Work landed after the note was written. Compare the note's save time with the newest commit and session: STALE.

It cites a commit that doesn't exist

"Tests pass, commit 4f9e2a1." Ask git: cat-file -e 4f9e2a1^{commit}. Never made.

It misquotes its source

"NOTES.md: 'two hours a day'". The file says two hours a week. A word-for-word match catches it.

No model grades anything. Every check is deterministic, so it gives the same answer every time.

The truth boundary

Checked by the machine, or only written down

Checked

The note is newer than the work. Each cited commit is in the repo. Each quote is word for word in its file. Shown as yes or no.

Only written down

Next step, status, who it's for, why it matters: someone's words, with nothing checking them. Still useful, but labelled.

On the demo city: 22 of 26 checks hold, and 76 lines are someone's word.

Silence is a finding too: a project with no note fails the gate instead of looking fine.

What another builder can learn

A note about your work is only true the moment you write it

Notes go stale

Compare when the note was written with the newest commit and session. If the work is newer, the note is labelled "written before the latest work" and the gate fails.

Fix it where every call goes through

A server restart broke every open tab: a new token, so every call got refused. The fix went into the one helper every call uses, not into the screen that was reported.

My tests passed for free

The mutation script said every breakage was caught. The copy it tested couldn't find its own files, so even good code failed. New rule: the baseline must pass first.

More hard-won ones

Environment looks like a bug

Windows "Animation effects" off made Chrome ask for reduced motion. The city froze and browser tests failed, with no code change.

Invisible is worse than wrong

A NaN tower height drew nothing, with no error. A wrong building is a bug you can see; a missing one looks like a design choice.

Measure, then speed up

A 40-project scan took 5s: 138 git calls in a row. A thread pool brought it to 1.7s.

Port the concept, not the stack

The ideas came from my Postgres/Express/React grader. Here each one is about 30 lines of stdlib Python.

Take it home, even without Product Library

Five habits

  • End every session with: next concrete step, proof it worked, who owns each blocker. "Continue" is not a next step.
  • Treat any status note as stale once the work is newer than the note.
  • Verify AI-cited evidence with a deterministic check before believing it.
  • Keep what was checked apart from what was only claimed.
  • Mutation-test your tests, and make sure the baseline passes first.

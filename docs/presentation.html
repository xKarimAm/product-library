A dashboard that checks its own notes

Product Library

Every project I've started with Claude Code, as a city. It shows which notes about my work are still true.

Why I built it

It started with one file

.claude/session-state.md
stage: ship
next_action: "tag v1.0, add a README example"
proof: "6 tests pass; commit d948381"
blockers: []

Claude writes it at the end of every session. Weeks later I'd open it and ask: is this still true?

git log says what happened. It never says the note is out of date.

The idea

Three ways a note lies

It's out of date

Work landed after the note was written. Compare the times: STALE.

It cites a commit that was never made

Ask git if 4f9e2a1 exists. One command.

It misquotes its source

"Two hours a day." The file says a week. Checked word for word.

No AI grades anything. Same input, same answer, every time.

The truth boundary

Checked, or only written down

Checked

Note newer than the work. Commit in the repo. Quote in its file. Yes or no.

Only written down

Next step, status, why it matters. Useful, but nothing checked it.

Demo city: 22 of 26 checks hold. 76 lines are just words.

Live demo

Watch it stop trusting a note

Switch to the app. The guide on screen walks through each step.

PgDn next · PgUp back · T hides the guide

Take it home

End every session with three things

  • A next step. "Continue" is not one.
  • Proof it worked: a test run, a commit.
  • Who owns each blocker.

Then check the note against the work before you trust it.
